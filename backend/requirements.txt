# Browser rendering is deliberately NOT a production dependency.
#
# Supervisor discovery is static-first. The browser tier is an opt-in fallback
# for a university directory that publishes its staff list only after JavaScript
# executes, and it is reachable only when an operator sets
# SCHOLARZONE_SUPERVISOR_RENDER_ENABLED.
#
# The driver lives in requirements-supervisor-render.txt, not here. Its ~101 MB
# pushed this function's bundle to 270.22 MB against a 225 MB platform limit, so
# the build failed and nothing was deployed at all. A dependency that only a
# fallback tier needs must not be able to stop the service shipping.
#
# Nothing below this line changes behaviour when the driver is absent:
# supervisor_render.playwright_available() returns False, build_driver() returns
# a null driver, and such sources are recorded as source_requires_rendering -
# an honest inconclusive state, never a claim that a university has no staff.
# Static discovery needs no browser and is unaffected.
#
# To install the browser tier:
#   pip install -r requirements.txt -r requirements-supervisor-render.txt
#   playwright install chromium
# ---------------------------------------------------------------------------
